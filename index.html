Unlock Focus Mode

Follow the steps below to enable advanced features on your device.

1

Setup Your Phone

📱 A. Enable Developer Options

  1. Open Settings > About Phone
  2. Find Build Number (Software Info)
  3. Tap Build Number 7 times quickly
  4. You'll see "You are now a developer!"

🔌 B. Turn On USB Debugging

  1. Go back to Settings > System
  2. Open Developer Options
  3. Toggle USB Debugging to ON

🤝 C. Connect & Authorize

Connect via USB cable now.

  1. Watch your phone for a popup
  2. Check "Always allow from this computer"
  3. Tap OK

Troubleshooting

  • • Use a high-quality data cable
  • • Set USB mode to "File Transfer"
  • • Close other ADB apps (like Android Studio)

Grant Permission
